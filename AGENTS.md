# AGENTS.md

## Назначение проекта

`ports-checker` через SSH узнаёт TCP-порты, слушающие не-loopback интерфейсы
удалённого Linux-хоста, завершает SSH-сеанс и проверяет доступность только этих
портов с локальной машины. Разрешённые порты не считаются ошибкой. Доступный
неразрешённый порт должен приводить к коду завершения `1`.

## Стек и команды

- Common Lisp, основной поддерживаемый implementation — SBCL.
- Аргументы CLI описываются через `defmain`; не добавлять собственный цикл
  разбора `argv`.
- Зависимости управляются Qlot; не редактировать `.qlot/` вручную.
- CLI запускается как `qlot exec ./roswell/ports-checker.ros`.
- Установка зависимостей: `qlot install`.
- Тесты: `qlot exec ros -Q -e '(asdf:load-asd (truename
  "ports-checker.asd"))' -e '(asdf:test-system "ports-checker")' -q`.

## Правила разработки

- Использовать package-inferred ASDF: пакет файла должен соответствовать его
  пути (`src/foo.lisp` → `ports-checker/foo`).
- Определять пакеты через `uiop:define-package`, явно импортировать и
  экспортировать символы.
- Публичные функции снабжать docstring; строки держать не длиннее 100 символов.
- Тесты писать на Rove и размещать в `tests/`.
- Не заменять точечную проверку полным сканированием и не добавлять `nmap`.
- Не выполнять внешнюю проверку портов до завершения SSH-команды.
- Не подавлять ошибки SSH: инфраструктурная ошибка должна завершать CLI с кодом
  `2`, а не создавать ложный успешный результат.
- Сетевые границы подменять в unit-тестах; тестовый набор по умолчанию не должен
  требовать доступного SSH-хоста или открывать реальные соединения.
